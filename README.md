SVCE Student Registration Portal — A modern React-based student registration system with course selection, animated course-specific visuals, student login, profile management, and offline-ready local assets.
SVCE Student Registration Portal

A modern and responsive Student Registration Portal developed for Sree Venkateshwara College of Engineering (SVCE).

The application provides a simple and user-friendly platform for students to register, select their course, manage their information, and access their profile.

✨ Features
🏫 Modern college-themed home page
📝 Student Sign Up and Login
🎓 Course/Branch selection
💻 Course-specific 5-second animations
🎨 4 unique built-in graphics for each course
📱 Responsive user interface
👤 Student profile management
✏️ Edit and update student information
🆔 Automatic Registration ID generation
🔐 Login using Registration ID, Name, or Email
🖼️ Student profile photo
⚡ Offline-ready course graphics
🚫 No external image dependency for course animations
🎓 Available Courses
Computer Science & Engineering (CSE)
Electronics & Communication Engineering (ECE)
Electrical & Electronics Engineering (EEE)
Mechanical Engineering
Artificial Intelligence & Data Science (AI & DS)
Civil Engineering
🛠️ Technologies Used
React.js
JavaScript
HTML5
CSS3
Vite
Local SVG graphics and assets
🎯 Project Goal

The main goal of this project is to create a professional, attractive, and easy-to-use digital registration system for college students while providing a smooth and engaging user experience.

🚀 Getting Started
npm install
npm run dev

Then open the local URL shown by Vite in your browser
